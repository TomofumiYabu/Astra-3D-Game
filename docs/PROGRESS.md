## 次に進める内容

1. **遊びの評価**: 無音でも何が起きたか伝わるか、最初の一投が気持ちよいか、狙いを変えたくなるかを試遊で確かめる。
2. **戦車×怪獣**: 同じ操作で、重い押し込み・巨体の転倒・二次衝突を作る。見た目だけの置き換えにしない。
3. **ケーキの空輸**: 段の分離と巻き込み、人形の着地点を狙う一つのステージとして追加する。
4. **見せ方**: 人物の関節、専用モデルと材質、初撃と連鎖の構図を改善する。現状はプロシージャルな試作で、AAA品質には達していない。
5. **配信と配布**: 動画ファイルへの書き出し、バンドル分割、実GPU・Firefox・Safari・スマートフォン・ゲームパッドの評価。

計画の詳細は [改善方針](THROWING_GAME_DIRECTION.md)。現在のリプレイはアプリ内再生であり、動画ファイルの保存機能はない。人の試遊評価、SNS拡散効果、別Cloudタスクへの復元は未検証。

## 運用

検証済みの変更を意図の分かる粒度でcommit・pushする。deploy後は実公開URLでも確認する。検証結果のみの文書commitでは `[skip ci]` を利用できる。提案・実装・自動検証・公開・人による評価を混同しない。
