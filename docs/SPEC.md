# 仕様書 — ホテル・アストラ

最終更新: 2026-10-15（日本時間）。段階: 0.1 / 最初の動作プロトタイプ。

この文書は公開済みホテル試作の動作仕様。2026-10-16のユーザー指示による次期企画は [投擲ゲームの改善方針](THROWING_GAME_DIRECTION.md) に記録する。ホテル・荷物に限定しないステージ案は、まだゲーム本体へ実装していない。

## 企画

仮題: **お荷物、飛ばします。** 高級ホテルのベル係が、巨大なスーツケースを「丁寧に」発射する物理コメディ。五つ星の静かな空間と大惨事の落差を、短い動画でも理解できる形にする。

ユーザーが選択した方針: 巨大な荷物を弾くホテルの物理コメディ、PCブラウザー優先。開発・テスト・修正はCodex Cloudで完結する。

## 最初の体験

1. ロビー・発射する赤いスーツケース・積み上がった荷物が一画面に見える。
2. 左右キー / A・D / スライダーで角度を調整（±22°）。
3. Spaceまたは発射ボタンを押してため、離すと発射。最大1.5秒で最大威力。
4. Rapierによる物理衝突で荷物が飛ぶ。6秒間の物理シミュレーション後に結果表示。
5. 動いた荷物の数に応じた架空の損害額と、ホテルからの一言を表示する。
6. ボタンまたはRキーで即座に再挑戦。Rは飛行中も使用可能。

目標所要時間は1プレイ約10秒。描画が遅い環境では、固定ステップの上限により実時間が延びることがある。

## 得点と状態

- 10個の標的。初期位置から0.65m超移動した荷物を一度だけ数える。
- 1個48,000円、3個目から1個につき12,000円の追加ボーナス。最大576,000円。
- 状態は loading → ready → flying → result。開始失敗はerror。
- フォーカス喪失・ポインターキャンセル時はためをキャンセルする。
- 最高額のみブラウザーのlocalStorageへ保存。保存が禁止されていても遊べる。

## 見た目と音

- アールデコ調のロビー、象牙色の柱、真鍮、深緑、赤いカーペット。
- 物理ベースの材質、影、暖色照明、フォグ、ACESトーンマッピング。
- 荷物はプロシージャルモデル。UIはホテルの案内状・事故報告書をイメージ。
- 発射・衝突・結果の簡易合成音。初期状態は無音、ユーザー操作でオン。
- 画面揺れは `prefers-reduced-motion` で無効化する。
- AAAゲームのような映像品質は将来の制作目標。この試作で同等品質・実GPU性能・SNS拡散は保証しない。

## 初回に含めないもの

- 登場人物のモデル、声、専用アニメーション、写実的な有料アセット。
- 破片を伴う建物破壊、リプレイ、録画書き出し、SNSへの投稿。
- マルチプレイ、認証、オンラインランキング、課金、バックエンド。
- スマートフォン最適化とゲームパッド、他ブラウザーでの動作保証。
- 公開ホスティング・ドメイン・本番デプロイ。

## 初回の受け入れ基準

- Cloud内で `npm ci` と `npm run check` が成功する。
- 本番バンドルがCloud ChromiumでWebGLフレームを描画する。
- 実操作で発射 → 実際の物理衝突 → 正の得点 → 結果 → 再挑戦が成立する。
- キーボードとポインター入力、ためのキャンセル、描画非対応時の案内が動く。
- 仕様・進捗・残課題・環境再開手順がリポジトリに残る。
