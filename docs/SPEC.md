# 仕様書 — それ、投げるんですか？

更新日: 2026-10-16（日本時間）。段階: 0.2 / おじさん×サイボーグの動作プロトタイプ。

## 遊び

本日の投擲物は、スーツ姿のおじさん。屋上会場の18体のサイボーグへ投げ、敵同士の衝突を連鎖させる。投げる → 連鎖 → おじさんが起き上がってネクタイを直す → 結果 → 再挑戦までを一ラウンドにする。

ホテルや荷物に限定しないというユーザー方針に沿った最初のステージ。戦車・怪獣・ケーキなどの計画は [改善方針](THROWING_GAME_DIRECTION.md) を参照。巨大化で猫を救う案は独立企画で、このゲームに含めない。

## 操作と隊列

- 左右キー / A・D / スライダーで角度を±24度に調整。
- Spaceまたは発射ボタンを長押しし、離すと発射。最大チャージ1.2秒。短いタップにも最低威力がある。
- Rキーまたは結果画面のボタンで即再挑戦。飛行中もRでリセットできる。
- 正面突破・左右包囲・千鳥ドミノの3隊列。すべて18体で、初期配置が異なる。
- 隊列は `?formation=breakthrough` / `pincer` / `domino` で共有できる。不明な値は正面突破へ戻す。
- 隊列変更は待機中に行う。発射後の変更は無効。
- フォーカス喪失・ポインターキャンセル・タブ非表示時にはチャージをキャンセルする。

## 物理と得点

Rapierの実剛体を1/60秒の固定ステップで進める。1描画フレームで進める時間の上限は0.5秒。非表示のタブはゲーム時間を進めない。

おじさん、または既に衝突に巻き込まれた敵との実接触を起点にする。動いている接触元の速度が一定以上の場合に、接触先へ一度だけ上向き・外向きの補助インパルスを与える。接触していない敵を距離判定だけで飛ばさない。

- 撃破: 巻き込まれた敵を一体一回だけ記録。
- 二次連鎖: おじさんからの直接接触ではなく、巻き込まれた敵から新しい敵へつながった回数。
- 連鎖の深さ: 直接接触を1とする、接触のつながりの最大段数。
- 最長吹き飛び: 巻き込まれた敵の初期位置からの水平距離の最大値。
- 得点: 撃破×1,000 + 二次連鎖×600 + (最大深さ−1)×300 + 最長距離×100。距離の採点上限は200m。撃破ゼロなら得点ゼロ。

敵が落ち着き、最後の新しい衝突から1.4秒以上経過した場合は5秒以降に終了。落ち着かない場合も8秒を上限にする。その後、約2.2秒の起き上がり・ネクタイ演出を見せてから結果を表示する。

キャラクター全体の剛体と、描画上の腕・ネクタイの姿勢を組み合わせる。精密な全身ラグドールではない。起き上がりはラウンド終了後の描画演出で、得点へ影響しない。

## リプレイと共有

- 物理の姿勢・得点・時刻を30Hzで記録し、0.75倍速で再生する。リプレイ時に物理を再計算しない。
- リプレイは現在の一ラウンド分をメモリーに保持する。再挑戦・再読み込みで消える。
- 「結果とお題URLをコピー」で結果文と同じ隊列のURLをコピーする。SNSへの自動投稿は行わない。
- クリップボードが使えない場合は、選択してコピーできる欄を表示する。
- 最高記録は隊列別にlocalStorageへ保存する。保存できなくてもゲームは動く。

## 描画と音

- 手続き生成のおじさん・サイボーグ・屋上会場・都市背景。
- Three.jsのPBR材質、環境反射、太陽光と影、距離フォグ、ACESトーンマッピング。
- 衝突の短いヒットストップ、カメラ追従、火花、連鎖表示、合成効果音。
- 音は初期オフ。画面のボタンからオンにできる。
- `prefers-reduced-motion` ではカメラの追従・揺れを抑え、CSSの動きを止める。
- 標準画質と軽量画質を切り替えられる。軽量は `?quality=low`、影512px・描画バッファ幅最大800px。物理と得点は共通。
- WebGL初期化失敗時は再読み込みとブラウザー設定の案内を表示する。
