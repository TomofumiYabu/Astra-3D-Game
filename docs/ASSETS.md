# 素材と出典

初回プロトタイプでは外部の画像・モデル・音楽を使用しない。

| 素材                                   | 作成方法・出典                                                 |
| -------------------------------------- | -------------------------------------------------------------- |
| ホテルロビー、床、柱、照明、植物、荷物 | 本リポジトリの `src/game/scene.ts` で生成                      |
| ロゴ、案内看板、favicon                | 本リポジトリのHTML・Canvas・SVGで作成                          |
| 効果音                                 | `src/game/audio.ts` のWeb Audioによる合成                      |
| フォント                               | ブラウザー／OSにあるフォントを参照。フォントファイルの配布なし |

Three.jsはMIT、RapierはApache-2.0のライブラリ。依存パッケージのライセンスファイルも参照する。今後のモデル、HDRI、テクスチャ、効果音は、導入時にURL・ライセンス・配布可否・必要な表記をここへ追記する。
