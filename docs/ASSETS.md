# 素材と出典

現在の投擲ステージでは、外部の画像・キャラクターモデル・音楽をダウンロードして使用していない。

| 素材                               | 作成方法・出典                                                    |
| ---------------------------------- | ----------------------------------------------------------------- |
| おじさん・サイボーグ               | 本リポジトリの `src/game/models.ts` で形状と材質を生成            |
| 屋上会場・都市・床テクスチャ・看板 | `src/game/scene.ts` のThree.jsとCanvasで生成                      |
| 環境反射                           | Three.js同梱 `RoomEnvironment`（MIT）のプロシージャルな環境を使用 |
| ロゴ・favicon・UI                  | 本リポジトリのHTML・CSS・SVGで作成                                |
| 効果音                             | `src/game/audio.ts` のWeb Audio合成                               |
| フォント                           | ブラウザー／OSのフォントを参照。フォントファイルの配布なし        |

Three.jsはMIT、RapierはApache-2.0。依存パッケージのライセンスファイルも参照する。今後モデルや音を導入するときは、出典URL・ライセンス・配布条件・必要表記を追記する。
